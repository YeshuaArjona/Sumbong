# SUMBONG (Smart Urban Monitoring & Barangay Online Notification Gateway)
Repository for the collaboration of Group #7-Sumbong

Sumbong is a web-based complaint and incident reporting system which allows residents to submit their complaints remotely. It lets them describe their report, add images or videos, monitor their complaint through ticketing mechanism, and follow-up the Barangay. On the other hand, it also benefits Barangay personnel to properly organize the concerns and handle them efficiently and faster.
